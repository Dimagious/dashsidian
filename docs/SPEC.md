# Dashy — ТЗ v1

**Решение:** один плагин, шесть блоков, конфиг на YAML, без зависимости от Dataview.

**Одна строка:** собери дашборд из блоков, не написав ни строки кода.

## Почему не тема и не комплект

| вариант | дистрибуция | может нарисовать плитки | вердикт |
|---|---|---|---|
| тема оформления | стор, в один клик | **нет** — тема не создаёт DOM | мимо |
| комплект заметок и CSS | только руками: свой сайт, посты | да | нет канала раздачи |
| **плагин** | стор, автообновления | да | берём |

## Почему без Dataview

| | с Dataview | без |
|---|---|---|
| установка | два плагина, объяснять зачем | один клик |
| данные | через чужой API | `metadataCache.getFileCache(f).frontmatter` |
| риск | Datacore обещают годами, API может поехать | свой код |
| цена | −80 строк | +80 строк |

Восемьдесят строк дешевле зависимости. И «работает без Dataview» — строчка в описании стора.

## Блоки

| блок | роль | статус |
|---|---|---|
| `tiles` | сетка плиток-ссылок со счётчиками | **в v0.1** |
| `heatmap` | год по дням | **в v0.1** |
| `stats` | карточки чисел с агрегатом и трендом | v1 |
| `progress` | полосы к цели | v1 |
| `today` | строка дня со ссылками на periodic notes | v1 |
| `countdown` | сколько осталось до даты | v1 |

Навигация, история, счёт, цель, сегодня, впереди. Шесть ролей, пересечений нет.

Актуальный справочник по синтаксису генерируется из `src/blocks/schema.json`:
`docs/SKILL.preview.md`.

### stats

````
```stats
- { label: Заметок,       source: 01-Areas, agg: count }
- { label: Сон,           source: Дневник, field: sleep_score, agg: avg, trend: 30d }
- { label: Без пропусков, source: Дневник, field: training_readiness, agg: streak }
```
````

`agg`: `count | sum | avg | min | max | latest | streak`. Блок написан.
`trend: 30d` рисует спарклайн в карточке — ещё не сделан, в схему ключ не внесён,
чтобы агент не писал конфиг, который не рисуется.

### progress

````
```progress
- { label: Книг за год, source: Books, where: "year = 2026", agg: count, goal: 50 }
- { label: Объём бега,  source: Дневник, field: distance_km, agg: sum, goal: 200, unit: км }
```
````

### today

````
```today
daily: true
weekly: true
monthly: true
```
````

Папки и форматы берёт из Periodic Notes, если тот установлен; иначе из настроек плагина.

### countdown

````
```countdown
- { label: IRONMAN 70.3, date: 2026-11-15 }
- { label: Отпуск, date: 2026-12-20, icon: 🏖 }
```
````

## Агенты как первый класс

Две аудитории, не одна.

| кто | что ему нужно |
|---|---|
| человек | писать пять строк YAML вместо DataviewJS |
| агент | знать синтаксис, чтобы сгенерировать эти пять строк |

Без скилла агент не угадает формат и напишет то, что знает — DataviewJS.

**Единый источник правды.** Схема блоков лежит в `src/blocks/schema.json`. Из неё
`npm run build:skill` собирает три артефакта:

| артефакт | кому |
|---|---|
| `src/skill/skill-content.ts` | плагину — его он кладёт в хранилище |
| `docs/dashy.schema.json` | любому другому инструменту |
| `docs/SKILL.preview.md` | человеку, посмотреть глазами |

Валидатор ключей в блоках читает ту же схему. Расхождение документации с
поведением невозможно по конструкции; CI держит это гейтом `build:skill -- --check`.

**Установка.** Кнопка в настройках пишет `.claude/skills/dashy/SKILL.md` в хранилище.
Только по нажатию, никаких тихих записей за пределы своей папки. Версия скилла
хранится в настройках, чтобы предлагать обновление.

**Раздел «чего плагин не делает»** в скилле обязателен. Без него агент на «нарисуй
таблицу» сочинит несуществующий блок `table`. Вместо этого скилл отвечает: таблица —
это Bases, вот как сослаться на вид базы из плитки.

**Синтаксис проектируется под нейросеть.** Автор конфига пишет файл и уходит,
отрисовку не видит. Поэтому:

- принимаем и плоский inline, и вложенный YAML;
- синонимы ключей (`folder` = `source`, `title` = `label`, `emoji` = `icon`);
- неизвестный ключ — предупреждение, не падение, с подсказкой «возможно, `field`»;
- ошибка рисуется в блоке с номером строки.

## Что НЕ входит в v1

| не делаем | потому что |
|---|---|
| графики | Obsidian Charts |
| таблицы и запросы | Dataview, Bases |
| визуальный конструктор дашборда | отдельный продукт |
| канбан, задачи, месячный календарь | заняты |
| MCP-сервер плагина | тяжело, скилла хватает |
| платный тир | стор ждёт открытый и бесплатный |
| темы оформления | не наша война |

## Архитектура

```
src/
  main.ts              реэкспорт app/plugin
  app/plugin.ts        регистрация блок-процессоров, настройки
  core/                чистый слой, без Obsidian и DOM
    calendar.ts          раскладка года, серии подряд
    source.ts            отбор заметок: папка, тег, where
    aggregate.ts         count/sum/avg/min/max/latest/streak
    palette.ts           именованные цвета
  adapters/vault.ts    снимок metadataCache → NoteRecord[]
  blocks/              отрисовка, по файлу на блок
    schema.json          единый источник правды по ключам
  shared/parse.ts      YAML, синонимы, диагностика
  shared/render.ts     вывод диагностики и внутренних ссылок
  ui/settings.ts       настройки + установка скилла
  skill/               сгенерированное, руками не править
  styles/              main → variables + blocks
```

`isDesktopOnly: false`.

## Правила, оплаченные кровью

- **Токены объявлять на `body`, не на `:root`.** В `:root` (это `html`) обсидиановых
  переменных ещё нет; `color-mix` от несуществующего цвета невалиден, и плашки молча
  схлопываются в полную прозрачность.
- **Дату собирать из `getFullYear/getMonth/getDate`.** `toISOString()` переводит в UTC
  и в плюсовом поясе сдвигает локальную полночь на сутки назад, разъезжая всю сетку.
- **Блок обязан показывать свою ошибку.** Молча пустой блок — худший исход: у автора
  конфига может не быть другого канала обратной связи.

## Риски

| риск | ответ |
|---|---|
| Buttons частично пересекается с `tiles` | Buttons делает кнопку-команду, у нас сетка навигации со счётчиками |
| Heatmap Calendar уже есть | ему нужен DataviewJS, нам — нет |
| разрастание объёма | шесть блоков зафиксированы, седьмой только после релиза |
| очередь ревью в сторе | не блокирует: раздача через BRAT с первого дня |
| имя `Dashy` занято в сторе | проверить до первого релиза, переименование дешёвое, пока нет пользователей |

## Монетизация

Плагины в официальном сторе — открытый исходник и бесплатная установка. Это охват и
ремесло, а не выручка. Если нужна выручка — это отдельный продукт, не этот.
