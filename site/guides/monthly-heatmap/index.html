A year of days is a lot of grid when all you want to see is this month. One line, range, cuts the heatmap down to this month, this week, the last 90 days, a quarter or the year so far. The cells are shaded by your own numbers, the darkest for your best day in that window.

1A number in each daily note

The heatmap reads one property from your daily notes. A number shades the day by how high it is. A checkbox paints it when ticked.

Diary/2026-10-14.md
---
steps: 11240
gym: true
---

## 2026-10-14
  • 2026-10-14The note's name is its date. Anything after the date is fine: 2026-10-14 Wednesday counts too. A date in a property works as well, with date_field.
  • stepsAny number: steps, pages read, minutes of practice, a sleep score. Durations such as 1h 30m are read as minutes.
  • DiaryThe folder the block reads from. Use the one your daily notes already live in.

2This month on one grid

Make a note, say Steps.md, and paste this block.

Steps.md
```heatmap
source: Diary
field: steps
range: month
title: Steps this month
```
  • range: monthFrom the 1st of this month to today. On the 1st of next month it starts over by itself.
  • ColumnsOne column per week, one row per weekday, the same shape as the year grid. Today has a ring around it.
  • ShadingSet by the lowest and highest value in this window, not the whole year. A slow month still has a darkest day.
  • Click a dayOpens that day's note. Hover shows the date and the value.
Want it shaped like a calendar?

Add layout: calendar and the month is drawn with weekday columns and day numbers, a dot under each day that has a value. Dots rather than shades, so it suits habits best. The monthly habit calendar guide covers it.

3Any other window

Change the one line. Everything else in the block stays the same.

rangeDraws
weekThis week to today, from your first day of the week
monthThis month to today
year1 January to today: the year so far
30d, 90d, 365dThe last 30, 90 or 365 days, ending today
2026-10October 2026
2026-W40Week 40 of 2026
2026-Q4October to December 2026
{ from: 2026-09-01, to: 2026-11-30 }Those days, both included. from alone runs to today

A period written out is drawn whole once it is over. While it is still running, it is drawn up to today, so 2026-Q4 in early October is a few days long.

The picture at the top is three blocks in one note: month, 90d and year.

There is no word for "this quarter" that moves by itself. For a quarter that follows the calendar, write it out (2026-Q4) or use range: note in a quarterly note, as in the next step. For a rolling quarter, 90d.

4A month per monthly note

If you keep a note per month, named like 2026-10, put the block in its template with range: note. Each monthly note then shows its own month, and October still shows October when you open it in March.

Months/2026-10.md
```heatmap
source: Diary
field: steps
range: note
```
  • range: noteThe period the note's name stands for: 2026-10 is a month, 2026-W40 a week, 2026-Q4 a quarter, 2026 a year.
  • In the templateThe block shows a hint there instead of an error, and works in each note made from it.

Ask your agent

With Dashy's skill installed, an AI agent can write this from a request in plain words: it looks at your property names and folders first, then writes the blocks. Open the note in Reading view and paste any error a block shows back to the agent.

Prompt
In a new note called Steps, show my daily steps as a heatmap of this month, then the last 90 days, then the year so far, one under the other.

What comes back is something like the note above. The agent's YAML may differ from the guide's, with your own property names and titles, but it should do the same, and this guide is the reference to compare it against. More on working with an agent.

The same with Heatmap Calendar

Heatmap Calendar draws from a dataviewjs script, so it needs Dataview too. This is the shape its README gives:

With Heatmap Calendar and Dataview
```dataviewjs
const calendarData = {
  year: 2026,
  entries: [],
}
for (let page of dv.pages('"Diary"').where(p => p.steps)) {
  calendarData.entries.push({
    date: page.file.name,
    intensity: page.steps,
  })
}
renderHeatmapCalendar(this.container, calendarData)
```
  • It draws one calendar year. A single month (#7), a week, month or quarter (#72) and the year to date (#95) are open feature requests.
  • You can filter entries to a month in the script, but the grid around them is still the whole year.

Variations

A habit this month

A checkbox instead of a number: a ticked day is painted, the rest stay empty.

heatmap
```heatmap
source: Diary
field: gym
color: orange
range: month
```

Your own thresholds

Shades from fixed steps instead of this month's lowest and highest, with a legend.

heatmap
```heatmap
source: Diary
field: steps
range: month
bands: [12000, 9000, 6000]
```

Two habits, last 30 days

A colour each on one grid. More on layers.

heatmap
```heatmap
source: Diary
layers:
  - { field: gym, color: orange, label: Gym }
  - { field: read, color: green, label: Reading }
range: 30d
```

Autumn

Any stretch of days, both ends included.

heatmap
```heatmap
source: Diary
field: steps
range: { from: 2026-09-01, to: 2026-11-30 }
```

If a block shows an error

A block that cannot draw says why, inside the note. The usual three:

  • The grid is a whole year again. The range value was not understood, and the block says so in a warning. Check the spelling: month, 90d, 2026-10.
  • range: note in a note not named for a period. It works in notes named like 2026-10 or 2026-W40. Anywhere else, write the window out.
  • "steps" never contributed a value here. The property is misspelled, or the notes are in another folder.
