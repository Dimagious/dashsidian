Rules for every block

  • Quote a value with a colon, a comma or a hash in it: label: "Home: entry".
  • Synonyms work, folder for source for example, but the pages above list the main name first.
  • An unknown key does not break a block. It draws a warning, with the key it probably meant.
  • A block prints its own errors into the note, with the line number for broken YAML.

Not in Dashy

  • table: That is Obsidian Bases. Link to a base view from a tile instead: path: Vault.base#My view.
  • pie: Pie, doughnut, radar and scatter charts are the Obsidian Charts plugin. Dashy's chart draws lines and bars of a number over time only.
  • kanban: That is the Kanban plugin.
  • tasks: That are the Tasks or Dataview plugins.
