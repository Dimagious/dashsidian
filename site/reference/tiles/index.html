How it behaves

  • period: note on a badge: count tile counts the notes dated in the day, week, month, quarter or year the name of the note the block sits in stands for: in a note named 2026-W40, { label: Workouts, path: Training, badge: count, period: note } counts that week's workouts. period: 2026-10 or period: { from: 2026-09-01, to: 2026-09-30 } names the window outright. A note not named for a period is an error; a window that has not started yet shows no badge and says the day it starts.
  • A badge: count tile with period dates its notes by name, YYYY-MM-DD first, then the day format set in the Daily notes or Periodic Notes settings. Daily notes named another way with no such setting need the tile's own format: { label: Diary, path: Diary, badge: count, period: week, date_format: DD.MM.YYYY } counts 05.10.2026.md and its neighbours of this week.
