Keys on each tile

Each entry under items is one tile.

labelpathtagwhereperioddate_fieldiconsubbadgeaccentimage
KeyWhat it doesTypeDefault
label requiredalso title, name caption text none
path required where it leads; understands File.base#View text none
tag tag, with or without the hash; narrows badge: count text none
where a condition like year = 2026, rating >= 4, tags contains books, or several that must all hold: joined with and (year = 2026 and rating >= 4) or written as a list ([year = 2026, "rating >= 4"]). The field name may be a dotted path into a nested property, like health.sleep > 70. or is not supported; quote a value holding the word and or or. One unreadable condition drops the whole filter with a warning, and the count is drawn unfiltered. Narrows badge: count text or list none
period narrow badge: count to a window ending today: week, month, year (the current calendar one) or a rolling count of days like 30d. Notes without a date are left out first. A week starts on the first day of the interface language, Dashy's own when one is picked in its settings, otherwise Obsidian's: Sunday in English, Monday in most European languages text or number none
date_field a date frontmatter property to read instead of the note name for period: 2026-03-02 or 2026-03-02T10:30, or a dotted path into a nested property like meta.date; has no effect without period text none
iconalso emoji emoji text none
sub small caption under the title text none
badge count, meaning the number of notes in the folder narrowed by tag, where and period when given, or your own string text or number none
accent accent stripe on the left true or false none
image a cover image above the icon and label: a vault path (Attachments/gym.jpg), a [[wikilink]], or an https:// URL. A vault path that does not resolve, or anything other than those three, warns and the tile draws without a cover text none
